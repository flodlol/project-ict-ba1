Les 4 - Elektronica

Testen van de Dramco Uno

In dit labo konden we dan eidelijk aan het werk met onze Dramco Uno. Dat hebben we gedaan door de instructies op de website van Dramco te volgen.

We moesten beginnen met het installeren van de juiste software en drivers op onze computer zodat we de Dramco Uno konden programmeren en testen. Daarna konden we beginnen met het testen van de verschillende sensoren op de Dramco Uno door de voorbeeldcode te gebruiken die op de website van Dramco te vinden is. We hebben onder andere de temperatuur sensor, de licht sensor en de afstand sensor getest en ze werkten allemaal zoals het hoort.

Uiteindelijk konden we dan zelf aan de slag met ons eigen programma, op basis van opdrachten op de website. Dit is het uiteindelijk geworden: 


#include <DramcoUno.h>

#include 

void setup() {
  DramcoUno.begin();
  Serial.begin(9600);

  pinMode(10, OUTPUT);
  pinMode(4, INPUT_PULLUP);
}

void loop() {

  float temp = DramcoUno.readTemperature();
  int light = DramcoUno.readLuminosity();
  int blinkDelay = 1000 - (temp * 200);
  blinkDelay = constrain(blinkDelay, 100, 1000);


  String RoomValues =
    "T: " + String(temp) +
    " °C L: " + String(light) + " %";

  Serial.println("Values:");
  Serial.println(RoomValues);


  if (light < 10) {
    digitalWrite(10, HIGH);
  } else if (digitalRead(4) == LOW) {
    digitalWrite(10, HIGH);
    delay(blinkDelay);

    digitalWrite(10, LOW);
    delay(blinkDelay);
  } else {
    digitalWrite(10, LOW);
  };


  delay(200);
}

Ons programma maakt gebruik van de Dramco Uno library om gemakkelijk de verschillende sensoren te kunnen gebruiken en de gegevens te verwerken.

De kern van het programma is dat wanneer de licht sensor een waarde onder onze drempelwaarde van 10 detecteert, dat LED1 gaat branden. Verder is het ook zo dat als de knop ingehouden word, LED1 gaan branden op een frequentie afhankelijk van de temperatuur. Hoe hoger de temperatuur, hoe sneller LED1 zal knipperen.

Verder print het programma ook om de 2 seconden de temperatuur en licht waarde naar de seriële monitor, zodat we kunnen zien wat de sensoren detecteren.
